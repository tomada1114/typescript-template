# Security Policy

## Supported versions

Only the latest published release receives security fixes. A fix ships as a new release;
older versions are deprecated on npm rather than patched.

## Reporting a vulnerability

Report a vulnerability privately through this repository's **Security** tab → **Report a
vulnerability** (GitHub private vulnerability reporting). Do not open a public issue,
pull request, or discussion for it.

Include what you can of:

- the affected version,
- a minimal reproduction or proof of concept,
- the impact you expect it to have.

You will get an acknowledgement on the report itself. Once a fix is released, the
advisory is published with credit to the reporter unless you ask otherwise.
